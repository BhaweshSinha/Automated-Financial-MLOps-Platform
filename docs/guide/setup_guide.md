# 🧭 Setup Guide  
## Automated Financial MLOps Platform – Multi-Asset Stock Direction Prediction

---

## 1. 📦 Overview

This guide provides step-by-step instructions to set up and run the **Automated Financial MLOps Platform** locally.

The system performs:

- Multi-asset stock data ingestion  
- Feature engineering on time-series data  
- Machine learning model training  
- Prediction of next-day stock direction  

---

## 2. ⚙️ System Requirements

Ensure your system meets the following requirements:

- **Python**: 3.9 or higher  
- **Operating System**: Windows / Linux / macOS  
- **RAM**: Minimum 8 GB recommended  
- **Internet Connection**: Required for data ingestion (Yahoo Finance API)
